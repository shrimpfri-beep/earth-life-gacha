    ❌ 관리자 코드가 일치하지 않습니다.

    코드 변경
    ☁️ 다른 기기·다른 네트워크 접속자까지 집계하기 — 클라우드(Firebase) 연동 설정

    GitHub Pages는 파일만 보여주는 곳이라 접속 기록을 모을 수 없습니다. 무료 Firebase 데이터베이스를 연결하면 모든 참여자의 기록이 이 화면에 실시간으로 모입니다. (약 10분, 한 번만)

    1. console.firebase.google.com → 프로젝트 만들기 (이름 예: earth-life, 애널리틱스는 꺼도 됨)
    2. 왼쪽 빌드 → Realtime Database → 데이터베이스 만들기 → 위치 싱가포르(asia-southeast1) → 잠금 모드로 시작
    3. Realtime Database의 규칙 탭 → 내용을 모두 지우고 아래 규칙 붙여넣기 → 게시
    4. 빌드 → Authentication → 시작하기 → 로그인 방법 → 익명 사용 설정 → 저장
    5. ⚙️ 프로젝트 설정 → 내 앱 → 웹(</>) 아이콘 → 앱 등록 → 나오는 firebaseConfig 코드를 통째로 복사해 오른쪽 칸에 붙여넣기
    6. 저장하고 연결 → 위 상태줄이 ☁️ 연결됨으로 바뀌면 설정이 들어간 index.html 받기 → GitHub에 같은 이름으로 덮어쓰기 업로드

                    🚀 GITHUB PAGES
                    
    깃허브(GitHub) 업로드 및 공유 링크 생성 가이드
    
                
    
                
            
    

            
            
    
                
    
                    
    
                        💾 1단계: 배포용 index.html 원클릭 다운로드
                    
    
                    
    
                        아래 버튼을 누르면 현재 게임 코드 전체가 index.html 단일 파일로 즉시 저장됩니다. 이 파일 하나만 깃허브에 올리면 바로 작동합니다!
                    
    
                
    
                
            
    

            
            
    
                
    
                    
    2단계: GitHub 저장소(Repository) 만들기 (1분 소요)
    
                    
      
                        
    1. github.com에 로그인한 뒤 우측 상단 [+] 버튼 → [New repository]를 클릭합니다.
      2. 
                        
    2. Repository name에 원하는 영어 이름(예: life-game)을 입력합니다.
      3. 
                        
    3. 공개 범위를 Public (공개)으로 체크하고 하단의 [Create repository]를 클릭합니다.
      4. 
                    
    
                
    

                
    
                    
    3단계: 다운로드한 index.html 파일 업로드하기
    
                    
      
                        
    1. 생성된 저장소 화면 중간의 [uploading an existing file] 링크(또는 Add file → Upload files)를 클릭합니다.
      2. 
                        
    2. 위 1단계에서 다운로드한 index.html 파일을 마우스로 끌어다 놓습니다(Drag & Drop).
      3. 
                        
    3. 화면 아래 초록색 [Commit changes] 버튼을 누르면 파일 업로드가 완료됩니다.
      4. 
                    
    
                
    

                
    
                    
    4단계: GitHub Pages 무료 웹 링크(URL) 활성화하기
    
                    
      
                        
    1. 저장소 상단 메뉴의 [Settings (⚙️ 설정)] 탭을 클릭합니다.
      2. 
                        
    2. 좌측 사이드바 메뉴에서 [Pages]를 클릭합니다.
      3. 
                        
    3. Branch 항목의 None 드롭다운을 눌러 main (또는 master)을 선택하고 옆의 [Save] 버튼을 누릅니다.
      4. 
                        
    4. 약 1~2분 뒤 페이지를 새로고침하면 상단에 https://본인아이디.github.io/life-game/ 형태의 접속 링크가 생성됩니다!
      5. 
                    
    
                
    

                
                
    
                    
    🔗 내 예상 배포 주소(URL) 미리 만들어 보기
    
                    
    
                        
                        
                    
    
                    
    
                        https://[아이디].github.io/[저장소이름]/
